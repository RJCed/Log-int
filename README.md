# Log-in't

### SPARCS Org Fair 2026 — Worst Login Page Entry

**Log-in't** is a login page where you literally have to **shoot the characters** instead of typing them.

## Goal

Log in using:

* **Username:** `ARJAY`
* **Password:** `123`

## Controls

* **WASD** — Move
* **Mouse** — Aim
* **Left Click / Spacebar** — Shoot

## How to Play

Shoot the letters/numbers you need **in order**.

* **Enter** — Move to the password
* **Del** — Delete the last character

Click the **Username** box to start the game and begin spawning enemies

## Secret Easy Mode

Enter this on your keyboard:

**↑ ↑ ↓ ↓ ← → ← → B A Enter**

In Easy Mode, enemies only spawn using the characters from:

`ARJAY123`
